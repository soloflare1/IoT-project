# 🚀 Researchy — Deploy Guide
**Backend → Render (free) | Frontend → Vercel**

---

## 📋 আগে যা লাগবে

- [GitHub](https://github.com) account
- [Render](https://render.com) account (free)
- [Vercel](https://vercel.com) account (free)
- [MongoDB Atlas](https://www.mongodb.com/cloud/atlas) account (free)

## STEP 1 — MongoDB Atlas Setup

1. **atlas.mongodb.com** → Create free account
2. **"Build a Database"** → Free (M0 Sandbox) → Region: Singapore (closest to BD)
3. **Username & Password** তৈরি করো — মনে রাখো!
4. **"Add IP Address"** → `0.0.0.0/0` দাও (সব IP allow)
5. **Connect** → **"Connect your application"** → Connection string copy করো:
   ```
mongodb+srv://naba:EhYEm0c6LUR02xXu@cluster0.fabk82y.mongodb.net/?appName=Cluster0
   ```
   `<user>` ও `<password>` replace করো।

## STEP 3 — Backend → Render Deploy

### 3.1 Render এ যাও
1. **render.com** → Sign in with GitHub
2. **"New +"** → **"Web Service"**
3. GitHub repo connect করো → `researchy` select করো

### 3.2 Settings
| Field | Value |
|-------|-------|
| **Name** | `researchy-backend` |
| **Root Directory** | `backend` |
| **Runtime** | `Node` |
| **Build Command** | `npm install` |
| **Start Command** | `npm start` |
| **Plan** | Free |

### 3.3 Environment Variables
**"Environment"** tab → এগুলো add করো:

| Key | Value |
|-----|-------|
| `NODE_ENV` | `production` |
| `MONGO_URI` | তোমার Atlas connection string |
| `JWT_SECRET` | যেকোনো লম্বা random string (e.g. `k9#mP2$xQr8nLvZ1`) |
| `JWT_EXPIRES_IN` | `7d` |
| `CLIENT_URL` | পরে Vercel URL দেবে (আপাতত `*`) |

### 3.4 Deploy
**"Create Web Service"** click করো।

⏳ 2-3 মিনিট লাগবে। Deploy হলে URL পাবে:
```
https://researchy-backend.onrender.com
```

### 3.5 Test করো
Browser এ এটা open করো:
```
https://researchy-backend.onrender.com/api/health
```
দেখাবে: `{"status":"ok"}` ✅

## STEP 4 — Frontend → Vercel Deploy

### 4.1 frontend/src/utils/api.js আপডেট করো

```js
const api = axios.create({
  baseURL: import.meta.env.VITE_API_URL || "/api",
  // ...
});
```

### 4.2 frontend/.env.production ফাইল তৈরি করো

```env
VITE_API_URL=https://researchy-backend.onrender.com/api
```

### 4.3 Vercel এ যাও
1. **vercel.com** → Sign in with GitHub
2. **"Add New Project"**
3. তোমার `researchy` repo import করো

### 4.4 Settings
| Field | Value |
|-------|-------|
| **Framework Preset** | `Vite` |
| **Root Directory** | `frontend` |
| **Build Command** | `npm run build` |
| **Output Directory** | `dist` |

### 4.5 Environment Variable
**"Environment Variables"** section এ:

| Key | Value |
|-----|-------|
| `VITE_API_URL` | `https://researchy-backend.onrender.com/api` |

### 4.6 Deploy
**"Deploy"** click করো।

⏳ 1-2 মিনিট। URL পাবে:
```
https://researchy.vercel.app
```

## STEP 5 — CORS Fix (গুরুত্বপূর্ণ!)

Vercel URL পাওয়ার পর Render এ যাও:

**Render Dashboard → researchy-backend → Environment**

`CLIENT_URL` এর value আপডেট করো:
```
https://researchy.vercel.app
```

তারপর **"Manual Deploy"** → **"Deploy latest commit"** করো।

## ⚠️ Render Free Plan সম্পর্কে জানো

Render free plan এ server **15 মিনিট idle থাকলে sleep** করে।
পরের request এ **~30 সেকেন্ড** wake-up time লাগে।

**Fix:** [UptimeRobot](https://uptimerobot.com) (free) দিয়ে প্রতি 10 মিনিটে ping করাও:
- Monitor URL: `https://researchy-backend.onrender.com/api/health`
- Type: HTTP(S)
- Interval: 10 minutes
