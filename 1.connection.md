## <span style="color:#2F75B5;">Wiring Layout</span>

```text
RED     → VCC / Power
BLACK   → GND
BLUE    → I2C SDA
ORANGE  → I2C SCL
GREEN   → GPIO / Signal
PURPLE  → Serial RX/TX
```

```text
ESP32
│
├── GPS (Blue)
│   ├── TX → GPIO16
│   └── RX → GPIO17
│
├── GSM (Orange)
│   ├── TX → GPIO27
│   └── RX → GPIO14
│
├── OLED (Blue)
│   ├── SDA → GPIO21
│   └── SCL → GPIO22
│
├── SOS BUTTON (Purple)
│   └── GPIO4
│
└── BUZZER (Green)
    └── GPIO5
```

## <span style="color:#2F75B5;">GPS Serial Configuration</span>

```cpp
gpsSerial.begin(9600, SERIAL_8N1, 16, 17);
```

Meaning:

* GPS TX → ESP32 GPIO16
* GPS RX → ESP32 GPIO17
