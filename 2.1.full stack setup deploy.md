# Researchy 📚
A modern full-stack research archive platform built with MERN stack.

---

## 🗂 Project Structure

```
researchy/
├── backend/
│   ├── server.js                  # Entry point
│   ├── config/db.js               # MongoDB connection
│   ├── models/
│   │   ├── User.js                # User schema
│   │   └── Paper.js               # Paper schema (full-text indexed)
│   ├── controllers/
│   │   ├── authController.js      # register, login, getMe
│   │   └── paperController.js     # CRUD + search + pagination
│   ├── routes/
│   │   ├── authRoutes.js
│   │   └── paperRoutes.js
│   ├── middleware/
│   │   ├── authMiddleware.js      # JWT protect
│   │   ├── upload.js              # Multer (PDF/DOCX, 20MB)
│   │   └── errorHandler.js        # Global error handler
│   └── .env.example
│
└── frontend/
    ├── index.html
    ├── vite.config.js
    └── src/
        ├── main.jsx
        ├── App.jsx                # Routing + auth state
        ├── styles/global.css      # Design tokens + utilities
        ├── utils/api.js           # Axios instance w/ interceptors
        ├── hooks/useAuth.js       # Auth state hook
        ├── components/
        │   ├── Logo.jsx           # SVG logo + wordmark
        │   ├── Navbar.jsx         # Sticky nav with auth state
        │   └── PaperCard.jsx      # Reusable paper card
        └── pages/
            ├── Login.jsx
            ├── Register.jsx
            ├── Dashboard.jsx      # Stats + recent papers
            ├── Papers.jsx         # Search + paginated list
            ├── PaperDetail.jsx    # Full paper view + download
            └── UploadPaper.jsx    # Multi-field upload form
```

## ⚡ Quick Start

### 1. Clone & install

```bash
git clone <your-repo>
cd researchy
```

### 2. Backend

```bash
cd backend
npm install

# Copy and fill in your values
cp .env.example .env
```

**.env**
```
PORT=5000
MONGO_URI=mongodb://localhost:27017/researchy
JWT_SECRET=change_this_to_a_long_random_string
JWT_EXPIRES_IN=7d
```

```bash
npm run dev   # starts on http://localhost:5000
```

### 3. Frontend

```bash
cd frontend
npm install
npm run dev   # starts on http://localhost:5173
```

## 🔌 API Reference

| Method | Endpoint | Auth | Description |
|--------|----------|------|-------------|
| POST | `/api/auth/register` | — | Create account |
| POST | `/api/auth/login` | — | Login, returns JWT |
| GET | `/api/auth/me` | ✅ | Get current user |
| GET | `/api/papers` | ✅ | List papers (search, page, limit, year, keyword) |
| POST | `/api/papers` | ✅ | Add paper (multipart/form-data) |
| GET | `/api/papers/:id` | ✅ | Get single paper |
| PUT | `/api/papers/:id` | ✅ | Update paper |
| DELETE | `/api/papers/:id` | ✅ | Delete paper |
| GET | `/api/health` | — | Server health check |

### Search example
```
GET /api/papers?search=transformer&page=1&limit=10&year=2023
```

## ✨ Features

- 🔐 JWT authentication (register / login / protected routes)
- 📄 Upload papers with PDF/DOCX file attachment (max 20MB)
- 🔍 Full-text search across title, author, abstract, keywords
- 📑 Pagination on paper list
- 🏷 Keyword tagging system
- 🗂 Paper detail page with download link
- 📊 Dashboard with stats (total papers, unique authors, topics)
- 🎨 Modern UI with design tokens, custom Logo, sticky Navbar

## 🛠 Tech Stack

| Layer | Tech |
|-------|------|
| Frontend | React 18, Vite, React Router v6 |
| Styling | Plain CSS with design tokens |
| HTTP | Axios with interceptors |
| Backend | Node.js, Express |
| Database | MongoDB + Mongoose |
| Auth | bcryptjs + JWT |
| File upload | Multer |
| Dev | Nodemon, morgan |
