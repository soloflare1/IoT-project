# 🟢 WHAT IS `.env`?

`.env` = a file where we store **secret configuration values**

Example:

* API keys
* Backend URL
* Database URL

---

# 📁 WHERE TO CREATE IT?

Inside your **Frontend folder**:

```text id="env1"
Frontend/.env
```

NOT inside src ❌
NOT in backend ❌

---

# ✍️ WHAT TO WRITE INSIDE `.env`

```env id="env2"
VITE_GOOGLE_MAPS_KEY=YOUR_API_KEY_HERE
VITE_API_URL=https://safesteps-1.onrender.com
```

---

# 🚀 HOW IT WORKS

```text id="flow1"
.env file → React reads it → Map loads → API connects backend
```

---

# ⚠️ VERY IMPORTANT RULE

✔ Must start with `VITE_`
❌ Otherwise React will NOT read it

---

# 🔥 AFTER ADDING .ENV

You MUST restart frontend:

```bash id="cmd1"
npm run dev
```
